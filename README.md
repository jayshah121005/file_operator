# File Operator

## Project Overview

File Operator is a simple Python project based on **file handling**.
The project allows the user to perform different operations on a text file through a menu-driven program.

The main purpose of this project is to understand how files can be created, read, written, searched, and deleted using Python.

## Features

The project provides the following operations:

* Create and write data to a file
* Read data from a file
* Add new data to an existing file
* Search for specific text in a file
* Delete the file data
* Handle file-related errors
* Simple menu-driven interface

```bash

```

### 3. Run the Python file

```bash

```

## Example

When the program starts, the user can select an operation from the menu.

```text
===== FILE OPERATOR =====

1. Write to File
2. Read File
3. Append to File
4. Search in File
5. Delete File Data
6. Exit

Enter your choice:
```

The user can then choose the required operation.
